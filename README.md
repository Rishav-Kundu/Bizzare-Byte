## 📌 Project Overview

**Bizzare-Byte** is a full-stack **College Event Management System** designed to simplify the process of managing college-level events. The platform allows administrators and participants to efficiently handle event creation, registrations, and basic event-related workflows through a responsive web interface.

The project follows a **separation of concerns** architecture, with a clean frontend, a REST-based backend, and a relational database for persistent storage.

---

## 🛠️ Tech Stack

### Frontend

* **HTML5** – Structure
* **CSS3** – Styling & responsive layout
* **JavaScript (Vanilla JS)** – Client-side interactivity

### Backend

* **Node.js**
* **Express.js** – Server-side routing and API handling

### Database

* **MySQL** – Relational data storage

* **Railway** – Hosting backend services and MySQL database

## 🚀 Getting Started (Local Setup)

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Rishav-Kundu/Bizzare-Byte.git
cd Bizzare-Byte
```

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Configure Environment Variables

Create a `.env` file and add:

```env
DB_HOST=your_mysql_host
DB_USER=your_mysql_user
DB_PASSWORD=your_mysql_password
DB_NAME=your_database_name
PORT=3000
```

### 4️⃣ Run the Application

```bash
npm start
```

The app will run on:

```
http://localhost:3000
```
